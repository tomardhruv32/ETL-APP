| # | Scanner                     | Main Purpose                                                | Key Indicators                         |
| - | --------------------------- | ----------------------------------------------------------- | -------------------------------------- |
| 1 | **Breakout Scanner**        | Detect stocks breaking important resistance                 | Donchian, Volume, EMA, ADX             |
| 2 | **Momentum Scanner**        | Find stocks with strong upward momentum                     | RSI, MACD, ROC, Volume                 |
| 3 | **Trend Scanner**           | Find stocks already in a strong established trend           | EMA 20/50/200, ADX                     |
| 4 | **Pullback Scanner**        | Find strong stocks temporarily pulling back                 | EMA, RSI, ADX, Bollinger Bands         |
| 5 | **Volume Breakout Scanner** | Detect unusual buying activity before/alongside price moves | Volume SMA, Volume Ratio, Price Change |
